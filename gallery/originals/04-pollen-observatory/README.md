# The Pollen Observatory — five unstable constellations

**FIELDWEAVER original 04; original-authored recipe, not a mutation.** An installation of five displaced seedheads, arranged as a broken constellation rather than a horizontal or vertical register. This initial authoring candidate is paired with a native CPU software-raster transfer test: any claim about rendered appearance must await the actual FW-012 output.

## Composition

Five centres at world (45,66), (127,62), (210,86), (77,156), and (184,164) have intentionally nonuniform size, phase and petal ordering. Six filament emitters per centre define oblique radial spokes, each at its own onset and velocity; five fine ink hearts supply compact anchors, five offset dust emitters scatter spores, and five delayed shard emitters put crisp cuts through the last movement. There are **45 emitter definitions** across four behaviourally different materials; this is not an RGB flicker over a reused scene.

Six ordered fields establish a restrained early eight-sector lock, slow global draft, mild turbulence, and two asynchronous spatially bounded counterrotations. Seventeen explicitly ordered interventions progressively release the lock, gate each vortex, silence/recover one emitter, introduce an exactly frozen interval at ticks 91–96, begin the late shear, and reinstate quantization before the final fracture. Five independent versioned LUTs control chalk/pale-shell ink, iron-red-to-saffron filament, lichen spores, iris-purple shards, and age-varying dust steering. The deliberately blank intervals between the five heads are part of the composition.
